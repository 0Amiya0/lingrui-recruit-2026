# 多损失为何可能冲突，以及怎样平衡

MSE 约束像素，感知项关注特征，对比项约束相对关系。不同目标并不保证方向一致：
增强纹理可能偏离真实像素；远离有雨图可能破坏共享背景。多加损失还会增加预训练模型带来的偏差、梯度噪声和显存成本。

总目标 L=sum lambda_i L_i。即便各项数字接近，其对模型参数的梯度范数也可能差异很大；
仅用损失值除均值，不能保证实际参数更新贡献相等。

可设想在共享参数 theta 上测量 g_i=||grad_theta L_i||，用其指数滑动均值 gbar_i 归一化：
先计算 detached 的权重 w_i=lambda_i/(gbar_i+eps)，再用 sum w_i L_i 做正式更新。
还可将所有梯度范数相对于一个参考项归一化以维持总体更新尺度。权重应 stop-gradient，
eps、上下界、更新频率需要记录；不能为得到权重而无意引入二阶梯度。

这样只能让范数贡献更接近指定超参数比例，无法消除梯度方向冲突，范数相等也不代表感知效果相等。
可进一步分析梯度余弦，研究投影/多目标优化；没有理论保证任意损失组合都比单项好。
本项目按题目要求只描述思路，不实现自动梯度平衡；训练入口使用固定的显式 lambda。

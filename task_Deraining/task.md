对于一张带有雨的图像，如何得到无雨的图像？🤔

我们先来对比一下：在满足图像背景完全一致的情况下，两种图片之间唯一的差异，就是在图片中的雨丝。

一个直观的想法是：只要将雨丝从图像中”清除“掉，在这些被“清除”的地方补上无雨图像对应的部分，那么就能够得到无雨的图像啦！ ------ 用公式可概括为：无雨图像 = 有雨图像 - 雨层

当然，这是一道 ml 的题目，这些步骤需要交给我们的模型来学习和实现。从上文我们便能够猜想出模型在这个过程中需要干什么：

    模型接收到一张有雨的图像
    从图像中识别出雨丝
    将雨丝有关的像素根据其他的背景信息修复为应有的像素值（即去除雨丝并重建背景信息）
    输出一张与输入大小一致的图像

我们的问题随之而来：

    基础问题
        在之前我们学习到的图像分类模型中，我们对输入的每一张图像，是通过一层一层的卷积层，不断地从中提取信息，最终在展平（Flatten）为类别长度的一维向量后，通过 softmax 函数得到每一个类别的概率，从而进行预测；但在这里，我们的输出应该是一张和输入一样大的图像，但是我们其实只需要对每一个雨丝所在的位置进行改变。那么，**我们应该让模型学习什么？是直接让模型学会从有雨图像到无雨图像的端到端映射（直接学习），还是让模型只专注于学习雨层，然后从原图像中减去它（残差学习）？**请你思考后给出答案，并通过图像的方式表现你认为的模型应该是怎么样的
    附加问题
        雨丝这一物体，在外表上表现出的线性特征，其实也存在于其他物体中（如条纹、纹理等）。在面对这种情况时，模型如何分辨谁是雨丝？
        雨非常大时，密集的雨丝可能会完全遮挡住背景的一些细节（比如建筑的轮廓线）。在这种因干扰而难以分辨的情况下，模型还有可能复原出原来的物体吗？

仅凭主观感觉评估图像质量是不可靠的，因此我们需要一系列客观指标来衡量修复效果

    PSNR（峰值信噪比）

    峰值信噪比的定义如下：

    PSNR=10⋅log⁡10(MAXI213mn∑i=0m−1∑j=0n−1∑c∈{R,G,B}(Ic(i,j)−Kc(i,j))2)
    PSNR=10⋅log10​(3mn1​∑i=0m−1​∑j=0n−1​∑c∈{R,G,B}​(Ic​(i,j)−Kc​(i,j))2MAXI2​​)

    可以看到，其中：
        作为对数分子的，是表示图像点颜色的最大值（如果每个采样点用 8 位表示，就是 255）的平方。对于初学者而言，可以暂时将 MAX_I 理解为一个固定值
        作为对数分母的，是两张图像在所有像素上的均方误差 (MSE)。MSE 的计算方式源于 L2 范数，这使得 PSNR 指标对异常值（即差异特别大的像素点）非常敏感

    SSIM（结构相似性）

我们将在这里介绍一个经典的模型 ------ DeRainNet

其设计思路如下：

    将原始图片经过卷积，使得通道数变为 C
    将处理后的图片送入三个分支，分别按照原图大小、1/2 大小、1/4 大小的方式进行处理（使用 Maxpooling 下采样）
    使用不同 8 层 ResBlock（同上文 Residual Block）对每个分支图片处理后，与处理前的图片相加，并上采样回到原图片尺寸和通道数 C
    将三个分支的特征图上采样并拼接（Concat）起来，通过卷积层融合信息并最终输出一个3通道的图像，这个图像代表模型学到的雨层（Residual）。最终的去雨图像由原始输入图像减去这个雨层得到

你已经知道了余弦相似度的作用，接下来我们将尝试将其应用在去雨算法中

在房价预测中，我们把一条固定长度的数值向量称为特征向量，它的每个维度都代表了一种房屋特征。使用线性回归时，我们相当于在特征空间中，把这些特征向量映射到一个预测值

如果把特征向量看作从原点出发的点或箭头，那么在空间里，样本之间的位置关系就能体现相似性。通常我们会把向量归一化为单位向量，此时它们的长度相同，差别只在方向上。方向越接近，余弦相似度越大，也就是说这两个房子在特征上更相似。换句话说，在归一化的特征空间里，向量之间的夹角就能衡量样本之间的相似性

    **如果我们能够把这个思想用在去雨上，那么应该是什么样的？**🤔

    在题目开头，我们已经具备了 无雨 = 有雨 - 雨层 的基本意识。如果说我们拥有一个办法，将一张图片变为一条向量，那么我们就能通过余弦相似度计算出二者的相似性

    可以预见的是，有雨图像和无雨图像之间的差异应该是比较大的，余弦相似度应该会比较小

    也能很快明白，只要我们的模型生成的去雨图像，它所对应的特征向量，能和真实无雨图像的特征向量足够相似（比如方向接近），那么我们就可以认为，模型在特征层面（而不只是像素层面）学到了东西，性能很好

    **如何得到这个向量呢？**🤔

    我们在上文中使用到感知损失函数，通过一个预训练模型，将图像处理后，得到更能表现出差异的图片，再进行 L1 损失

    之所以更能表现出差异，是因为经过处理后的图片，更能表现出特征（换句话说，预训练模型正在逐步将图片编码为特征）

    也就是说，只要我们让预训练模型对图片处理后，同图像分类任务一样展平成为向量，那么就可以将这个向量看作由预训练模型抽离出的特征
